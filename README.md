# A Persistent Homology Pipeline for the Analysis of Neural Spike Train Data

Code and results accompanying the paper by Cagatay Ayhan, Audrey N. Nash,
Roberto Vincis, Martin Bauer, Richard Bertram, and Tom Needham.

**Publication status (October 30, 2026): accepted for publication in SIAM Journal
on Life Sciences (SIALS), to appear** 

[arXiv preprint](https://arxiv.org/abs/2512.08637v1)

## Repository organization

```text
notebooks/
  journal_version/       Analyses and figures for the accepted journal version
  arxiv_only/            Figures specific to the original arXiv preprint
metadata/                Recording-session information and trial counts
results/
  stability/             VP parameter sensitivity and sampling convergence
  synthetic/             Classification results for synthetic datasets
  gustatory_cortex/      TDA, SVM, and single-neuron classification results
  coordination_test/     Genuine versus shuffled macaque activity results
  supplementary/         Additional parameter sweeps and experiments
Datasets/                External recordings and input data (local; Git-ignored)
outputs/                 Generated figures and synthetic data (Git-ignored)
utils.py                 Data generation, distances, persistence, and classification
real_data_utils.py       Loading and extracting biological spike-train data
repo_paths.py            Data and output path configuration
environment.yml          Required Python environment
```

Notebook names identify the corresponding section and figure in the relevant
paper version. External datasets must be obtained separately; generated outputs
can be recreated by running the notebooks.

## Getting started

From the repository root:

```bash
conda env create -f environment.yml
conda activate spike-train-tda
jupyter lab
```

Open the notebook corresponding to the section of interest and run its cells in order. Some notebooks require external data.


## Data and implementation

Synthetic data are generated by the notebooks. GC recordings and Bayesian single-neuron scores are external inputs; see the [Vincis lab data/code repository](https://github.com/vincisLab/neuron-response-classification). The macaque experiment uses [CRCNS v1v2-1](https://doi.org/10.6080/K0B27SHN). Local datasets are kept under `Datasets/` and are not added to Git.

The pipeline treats each neuron ensemble as a metric space using Victor-Purpura
distance, computes persistence barcodes, compares them with bottleneck distance,
and classifies stimuli with 1-NN. General VP computations use Elephant; the
discrete-time special case uses `VP_trivial`. Persistent homology uses Ripser;
bottleneck computations use the custom degree-0 `bottleneck_zero`, Persim, or
GUDHI according to the notebook. Classification validation is experiment-specific:
the journal version analyses include repeated 70:30 holdout splits, while the
preprint code includes Leave-One-Out-Cross-Validation (LOOCV).
